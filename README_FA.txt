کافه جیگر — نسخه آنلاین واقعی

این نسخه مثل نمونه COFFEA2 دو صفحه مستقل دارد:
1) index.html = منوی مشتری
2) admin.html = پنل مدیریت

تفاوت مهم: اطلاعات دیگر در localStorage نیست و در Supabase ذخیره می‌شود؛ بنابراین تغییرات از دستگاه‌های مختلف قابل مشاهده است.

مراحل راه‌اندازی:
1. در Supabase یک Project بسازید.
2. بخش SQL Editor را باز کنید و کل فایل supabase_schema.sql را اجرا کنید.
3. در Authentication > Users یک کاربر مدیریت بسازید. برای سادگی می‌توانید رمز را 8585 بگذارید؛ رمز در رابط کاربری نمایش داده نمی‌شود.
4. فایل config.js را باز کنید و SUPABASE_URL و SUPABASE_KEY را از تنظیمات پروژه قرار دهید. فقط Publishable/anon key را قرار دهید؛ Service Role Key هرگز نباید در فایل‌های مرورگر باشد.
5. کل پوشه را روی GitHub Pages، Netlify، Vercel یا هر هاست استاتیک قرار دهید.
6. آدرس index.html همان لینک عمومی منو است. در پنل QR، همان آدرس را وارد کنید.

برای GitHub Pages:
- فایل‌ها را در یک repository قرار دهید.
- Settings > Pages > Deploy from branch را انتخاب کنید.
- لینک ساخته‌شده را در QR ثبت کنید.

نکته امنیتی:
نسخه آنلاین از Supabase Auth برای ورود مدیریت استفاده می‌کند. برخلاف رمز ثابت داخل JavaScript، این روش برای استفاده واقعی مناسب‌تر است. کلید Service Role را داخل مرورگر قرار ندهید.
